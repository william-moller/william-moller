### What's here

- **[Ugly Christmas Sweaters](https://github.com/william-moller/ugly-christmas-sweater)** — an online
  version of a licensed card game for Board Game Arena. It passed BGA's framework and visual review and
  is in public alpha. PHP state machine on the server, TypeScript client.

I build it agent-first with Claude Code. The repo commits its `CLAUDE.md` and `.claude/` docs, so you
can see the rules, architecture notes, and mistake log the agent works from.
